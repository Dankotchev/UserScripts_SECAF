# UserScripts para IBGEanos
Este repositório tem a intenção de compartilhar com a comunidade de servidores do IBGE userscripts para controlar as horas realizadas no Programa de Gestão de Demandas (PGD) e do código de afastamento 09-027 (PDI).

## Tampermonkey, a extensão necessária
Para utilizar os userscripts é necessário instalar a extensão "Tampermonkey" em seu navegador. Após a instalação, com um clique direito no símbolo da extensão, vá até "Gerenciar extensão" e ative a configuração "Permitir scripts de usuário".

## PGD - 64 Horas presenciais
1. Para utilizar acesso o link https://github.com/Dankotchev/UserScripts_SECAF/raw/refs/heads/main/Horas_PGD.user.js e na página aberta confirme o nome do userscript "PGD - 64 Horas presenciais" e clique em "Instalar".
2. Recarregue a página de "Apuração" e utilize o botão localizado no fim da página a direita.

## Saldo de Horas de Afastamento PDI
1. Para utilizar acesso o link https://github.com/Dankotchev/UserScripts_SECAF/raw/refs/heads/main/Saldo_Horas_PDI.user.js e na página aberta confirme o nome do userscript "Saldo de Horas de Afastamento PDI" e clique em "Instalar".
2. Recarregue a página de "Afastamentos" e utilize o botão localizado no fim da página a direita.
